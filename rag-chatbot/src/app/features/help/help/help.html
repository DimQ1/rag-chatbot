How to use the chatbot
  • Type your question in the message box and press Enter to send.
  • Use Shift+Enter to add a new line in the message box.
  • Use Up/Down arrows to browse previous and unsent draft questions.
  • Open source links under answers to check supporting documents.
 Account and navigation
  • Use the account icon in the chat toolbar to update your profile and password.
  • Use New chat to clear current conversation messages.
  • Admin users can open the Admin panel from the toolbar.
  • Use the Help menu in chat to open this page or About details.
