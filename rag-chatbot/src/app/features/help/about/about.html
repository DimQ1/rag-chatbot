RAG Chatbot

This assistant uses retrieval-augmented generation (RAG). It searches the configured knowledge base and answers using the most relevant sources.

Core functionality
  • Secure sign-in with email/password and optional Google login.
  • Role-based access for user and admin capabilities.
  • Conversational chat with source citations in every response when available.
  • Question input history support for quickly reusing previous or draft questions.
 Admin capabilities

Admin users can manage users, documents, and runtime RAG settings to keep answers accurate and up to date.
