# Security Policy

## Reporting a Vulnerability

Please do not open a public issue for security-sensitive problems.

Instead, share:

- the affected area
- reproduction steps
- impact assessment
- any suggested remediation

Treat all placeholder credentials in this repository as development-only examples. Replace them before any deployment or public demo connected to real services.

## Scope

Security issues may include:

- authentication or authorization bypass
- token leakage
- secret exposure
- unsafe configuration defaults
- dependency issues with practical exploit impact
